# Домашнее задание к лабораторной работе №6. 
## Условие задачи 
Составить программу, которая проверяет, принадлежит ли заданная пользователем точка с координатами (x,y) заданной заштрихованной области, и выводит на экран соответствующее сообщение.
## 1.Математическая модель 
Область состоит из двух прямоугольников: 
 Первый прямоугольник ограничен прямыми: x=-1,x=3,y=4,y=7
Второй прямоугольник: x=-4,x=-1,y=1,y=4
Точка попадает в область, если она находится внутри одного из прямоугольников. 
## 2.Реализация программы 
Фрагмент:

```
 if ((x >= -1 && x <= 3 && y <= 7 && y >= 4)||
	(x <= -4 && x >= -1 && y <= 4 && y >= 1))
{
	printf("Данная точка принадлежит закрашенным областям\n");
}
else
{
	printf("Данная точка не принадлежит закрашенным областям\n");
}
```

## 3.Результаты работы программы
Например, возьмем точку x=1,y=1. Точка не принадлежит области. 
Или x=0,y=5. Точка принадлежит области.
